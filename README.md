# NEXORA — Responsive Technology Landing Page

NEXORA is a modern technology company landing page designed to highlight a premium digital brand, product-led messaging, and a clear conversion path for potential clients. The single-page experience is built to feel polished, confident, and highly usable across desktop and mobile screens.

## Overview

This project presents a sleek, dark-themed marketing website with a strong blue accent palette, modern typography, and clean section-based content. It is crafted as a lightweight frontend experience focused on brand storytelling, service positioning, and clear calls to action.

## Technologies used

- HTML5
- CSS3
- Vanilla JavaScript

## Features

- Responsive navigation and mobile menu
- Hero section with call-to-action buttons
- About, services, why-us, showcase and contact sections
- Scroll reveal animations and hover interactions
- Dark visual design with blue accents

## Local setup

You can run the site locally with Python's built-in HTTP server:

```bash
python3 -m http.server 8000
```

Then open the following URL in your browser:

```text
http://localhost:8000/
```

You can also open `index.html` directly in a browser without a local server.

## Contact form behavior

The contact form is frontend-only and uses a `mailto:` action to open the visitor's default email application. It does not send data to a backend or require any server-side processing.
